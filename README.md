# 체육관 정리 로봇 — 수업 제출본

다른 업무로 대관마다 코트를 확인·청소하기 어려운 체육관 관리자를 위해, 사람 없는 시간에 코트 바닥을 밀고 벤치의 병·봉지를 집은 뒤 충전 자리로 돌아와 결과를 알려 주는 로봇. 4주 동안 시뮬레이션과 CAD 모델로 확인한다(1인 팀).

## 제출 문서 (교안 순서)

1. 1일차 — [D02 팀 차터](docs/charter.md): 목표, 역할, 범위
2. 2일차 — [D01 문제 정의서](docs/problem.md): 관리자 문제, 관찰과 확인할 가정, 현재 흐름, 해결 방향
3. 3일차 — [D03 요구사항 명세](docs/requirements.md): 요구 → 시스템 → 기능, 요구사항 표, 판정 기준
