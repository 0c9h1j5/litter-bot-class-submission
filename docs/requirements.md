# D03 요구사항 명세 — 체육관 정리 로봇

D03 · 요구사항 명세 · 1인 팀 · 상태 검토 · 2026-11-25 · 관련 [D01 문제 정의서](problem.md), [D02 팀 차터](charter.md)

## 1. 사용자 요구 → 시스템 → 기능

| 사용자 요구 | 시스템 (로봇 전체) | 기능 |
| --- | --- | --- |
| 관리자: 대관마다 들어가지 않아도 코트가 정리되고, 결과만 확인하고 싶다 | 사람 없는 시간에 청소·집기를 끝내고 충전 자리로 돌아와 결과를 남긴다 | 출발 판단, 이동·복귀, 결과 보고 |
| 이용자·청소 담당: 바닥이 밀려 있어 미끄럽지 않았으면 한다 | 코트 바닥을 빠짐없이 민다 | 줄 맞춰 밀기(옆솔·흡입·마른 패드) |
| 관리자: 벤치에 남은 병·봉지가 치워졌으면 한다 | 벤치·구석의 쓰레기를 집어 통에 담는다 | 인식, 집기, 통에 담기 |

## 2. 요구사항과 확인 방법

시뮬 장면은 농구 코트 일부 5 m × 3 m이고, 시드 10개로 10번 돌려 판정한다.

| ID | 요구사항 | 우선 | 확인 방법 |
| --- | --- | --- | --- |
| R-06 | 장면을 5 cm 칸으로 나눴을 때 패드가 한 번 이상 지나간 칸이 **95% 이상**이다 (분모 = 전체 칸 − 장애물 칸) | Must | 시뮬 |
| R-18 | 5 m × 3 m 장면 전체 청소 + 집기를 끝내고 충전 자리로 돌아오는 데 시뮬 시간 **650초 이하**, 끝난 위치가 충전 자리 **반경 0.1 m 안**이다 | Must | 시뮬 |
| R-04 | 병·캔·컵·구겨진 봉지를 통에 넣는 **수거율 80% 이상**이다 (한 판 10개 중 8개. 10번 평균 80% 이상, 가장 낮은 판 60% 이상) | Must | 시뮬 |
| R-25 | 사람 없는 시간에만 출발한다. 남은 시간이 650초보다 짧으면 출발하지 않는다 | Should | 시뮬 |
| R-14 | 한 판이 끝나면 결과 표 1개를 남긴다 (수거 수, 못 집은 것, 분실물 사진·위치, 커버리지, 건너뛴 칸, 시간) | Should | 시뮬 |
| R-32 | 관리자가 버튼으로 '벤치만 줍기'를 시키면 벤치 쓰레기 5개 중 4개 이상을 넣고 돌아온다 | Should | 시뮬 |

## 3. 판정 기준

한 판의 성공은 R-06·R-18·R-04를 모두 지키고, 아래 안전 조건을 어기지 않는 것이다. 숫자는 판정 기준이며 아직 달성한 결과가 아니다. 시뮬 10번 평가는 하지 않았다.

## 4. 안전·예외

- 코트에 사람이 있으면 출발하지 않고, 앞쪽 1 m 안에 사람이 오면 1초 안에 멈춘다. 장애물에 부딪히지 않고 정해진 구역 밖으로 나가지 않는다.
- 공·가방·신발·옷 같은 소지품과 물이 든 병은 집지 않고 사진·위치만 남긴다. 못 지나가는 칸은 건너뛰고 결과에 적는다.
