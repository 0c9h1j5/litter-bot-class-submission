# D02 팀 차터 — 체육관 정리 로봇

D02 · 팀 차터 · 1인 팀 · 상태 검토 · 2026-11-25

## 목표 한 줄

사람 없는 시간(첫 대관 전·마지막 대관 후·낮 빈 시간)에 체육관 코트 바닥을 밀고 벤치의 병·봉지를 집은 뒤 충전 자리로 돌아오는 로봇을, 4주 동안 MuJoCo 시뮬레이션으로 확인하고 축소판은 Fusion 360 CAD 모델로 설계만 확인한다(실물은 만들지 않음).

## 역할 (1인 팀)

| 역할 | 맡는 일 | 산출물 |
| --- | --- | --- |
| PM | 문제·요구사항 정리, 결정 기록 | D01, D02, D03 |
| 시뮬레이션 | 장면·로봇 모델, 반복 평가 | 시뮬 결과 |
| 개발 | 판정 함수, CAD 모델 | 코드, CAD |
| QA·운영 | 판정 테스트, 현장 확인(관리자 인터뷰·계수) | 추적표, 현장 기록 |

모든 역할을 한 사람이 맡는다. 결정은 PM이 내리고 이유를 기록한다.

## 범위

| 구분 | 내용 |
| --- | --- |
| 한다 | 코트 바닥 밀기(옆솔·흡입·마른 패드, 주 기능), 벤치·구석의 병·캔·컵·구겨진 봉지 집기(보조), 충전 자리 복귀, 결과 보고, 사람 1 m 안이면 멈춤, 시뮬 10회 평가, CAD 설계 확인 |
| 안 한다 | 대관 사이 정기 청소, 경기 중 운행, 관람석·계단·로비·실외, 젖은 바닥, 소지품·분실물 줍기(사진만 남김), 실물 제작·실물 시험(4주 뒤 로드맵), 실제 체육관 무인 운행(시설 동의 전제) |

## 일하는 방식

- 매일 한 일·막힌 일·할 일을 적는다.
- 커밋 전에 스스로 한 번 점검한다(AI 코딩 에이전트 리뷰 포함).
