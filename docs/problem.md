# D01 문제 정의서 — 체육관 정리 로봇

D01 · 문제 정의서 · 1인 팀 · 상태 검토 · 2026-11-25 · 관련 [D02 팀 차터](charter.md), [D03 요구사항 명세](requirements.md)

## 1. 문제

체육관 관리자는 대관 관리 말고도 다른 시설 업무를 함께 맡고 있어, 대관이 끝날 때마다 코트에 들어가 상태를 확인하고 청소하기 어렵다. 그래서 바닥 먼지와 벤치의 병·봉지가 다음 이용 전까지 남는다.

배경: 대관은 2시간 단위로 이어지고, 대관 시간에 준비·철수 시간이 들어 있다([공주시 국민체육센터 운영 안내](https://www.gongju.go.kr/nurim/main/sub05_01_01.do)). 그래서 대관 사이에는 대관 팀도 병만 줍고 나가며 바닥은 밀지 못한다. 이 짧은 교대 시간은 배경일 뿐, 로봇이 일하는 시간은 아니다.

## 2. 실제 관찰과 확인할 가정

숫자는 세 종류로 나눈다. **관찰**은 기획자가 1년 동안 체육관 약 10곳을 이용하며 본 것을 기억으로 정리한 값이다. **실측**은 현장에서 직접 센 기록이고, 지금 0건이다. **시뮬** 결과는 이 문서에서 쓰지 않는다.

| 구분 | 내용 |
| --- | --- |
| 관찰 | 경기 1회 뒤 생수병 약 1개, 과자 봉지 약 2개가 남는다. 쓰레기는 주로 벤치 쪽에 있고 쓰레기통은 입구 쪽이다. 바닥에 먼지·흙먼지·셔틀콕 깃털이 있어 미끄럽다. 사람이 쓰레기만 치우면 5~10분, 밀대질까지 하면 10~20분 걸린다. 대관 사이 밀대질은 거의 건너뛴다 |
| 가정 H1 (관리자 부담) | 관리자가 코트 확인·청소에 쓰는 시간과 횟수가 다른 업무를 밀어낼 만큼 크다 |
| 가정 H2 (청소 빈도) | 코트 바닥은 대관마다 밀리지 않고, 개점 전·폐점 후 하루 1~2번 이하로 밀린다 |
| 가정 H3 (효과) | 사람 없는 시간에 로봇이 치우면 관리자의 확인·청소 일이 줄고, 다음 팀이 덜 미끄러운 코트에서 시작한다 |

확인 방법: 관리자에게 지난주 실제 행동만 묻는다("코트를 몇 번 보러 갔고 한 번에 몇 분 걸렸나요?", "그때 밀린 일은 무엇이었나요?", "바닥은 누가 언제 밀었나요?"). 경기 직후 쓰레기 품목·개수와 사람 정리 시간(스톱워치)을 현장에서 센다. H3는 시뮬로 확인할 수 없고, 실제 체육관에서 로봇 전후를 비교해야 한다.

## 3. 사용자

| 사용자 | 상황 | 불편 |
| --- | --- | --- |
| A 관리자 (주 사용자, 구매) | 시설 담당 직원 또는 사설 체육관 운영자 | 다른 업무 때문에 대관마다 코트를 확인·청소할 수 없다. 대관 팀마다 정리 수준이 다르다 |
| B 청소 담당 | 개점 전·폐점 후 코트를 미는 사람 | 코트를 미는 동안 다른 구역 청소가 밀린다 |
| C 이용자 (다음 팀) | 첫 대관 팀, 빈 시간 뒤 팀 | 남은 병·봉지를 치우고, 미끄러운 바닥에서 경기한다 |

인물은 모두 가상이고, 관리자 인터뷰는 아직 하지 않았다.

## 4. 현재 흐름과 불편

경기 끝 → 대관 팀이 짐을 챙김 → 눈에 띄는 병만 주워 입구 쪽 통에 버림 → (밀대질은 건너뜀) → 다음 팀 입장 → 관리자는 틈날 때 확인, 바닥은 청소 담당이 개점 전·폐점 후에 밀거나 건너뜀

- 벤치 밑·구석 쓰레기가 남는다.
- 바닥 먼지·깃털이 남아 다음 팀이 미끄러운 코트에서 시작한다.
- 관리자는 언제 다시 봐야 할지 모르고, 볼 때마다 다른 일을 멈춘다(H1).

## 5. 해결 방향: 빈 시간 청소·집기·복귀와 결과 확인

1. 사람 없는 시간(첫 대관 전·마지막 대관 후·낮에 대관이 비는 시간)에만 출발한다. 코트에 사람이 있으면 출발하지 않는다.
2. 벤치·구석을 돌며 병·캔·컵·구겨진 봉지를 집어 로봇 옆 통에 담는다.
3. 코트 전체를 줄 맞춰 밀어 먼지·깃털을 치운다.
4. 충전 자리로 돌아온다. 사람이 들어오면 멈추고 물러난다.
5. 결과 보고를 남긴다: 수거 수, 못 집은 것, 건너뛴 칸, 분실물 사진·위치.
6. 관리자는 매번 코트에 들어가는 대신 결과를 보고, 못 치운 구역만 처리하거나 청소 담당에게 넘긴다. 로봇 통 비우기와 패드 교체는 관리자 몫이다.

대관 사이에는 정기 청소를 하지 않는다. 관리자가 원할 때만 버튼으로 '벤치만 줍기'를 시킨다(선택).

## 6. 성공 기준 (D03 연결)

판정 기준은 [D03](requirements.md)에 있다. 패드 커버리지 95% 이상, 5 m × 3 m 장면 청소·집기·복귀 650초 이하(충전 자리 반경 0.1 m 안), 수거율 80% 이상. 이 세 가지는 로봇이 일을 할 수 있는지를 보는 기준이고, 관리자 부담이 줄었는지(H1·H3)는 현장에서 따로 확인한다.
